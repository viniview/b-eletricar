# b-eletricar
## Visão do projeto
O b-eletricar é um projeto que visa sanar as curiosidades dos amantes e entusiastas de carros elétricos a respeito das especificações de cada automóvel. O projeto fornece catálogos das especificações base dos carros fornecidos (como marca, modelo, carroceria, preço, autonomia, etc) e oferece a opção de comparação entre modelos de diferentes marcas para o usuário compreender os pontos fortes e fracos de cada veículo e qual deles pode ser uma escolha melhor para seu gosto e bolso. Além disso, cada automóvel pode ser avaliado para que cada um possa compartilhar sua experiência e conhecimento com os demais usuários

## Descrições técnicas do site
O projeto utiliza como base um modelo em Spring Boot (versão 4.1.1) em conjunto com Thymeleaf, utilizando PostgreSQL e Docker Compose.
